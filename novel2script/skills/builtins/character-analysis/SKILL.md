# 角色分析报告 Skill

分析剧本中的角色数据，生成详细的角色分析报告。

## 功能说明

- 统计每个角色的出场次数
- 计算每个角色的对白占比
- 分析角色的情绪分布
- 生成角色关系图谱数据

## 输出格式

JSON 格式的分析报告，包含：
- 角色列表及统计数据
- 情绪分布数据
- 关系矩阵

## 使用方法

在 Skills 管理页面点击"运行"按钮。
