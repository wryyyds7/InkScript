# 章节概要

## 功能描述

分析剧本或小说，为每个章节生成概要总结。

## Prompt 模板

你是一个专业的文学编辑，擅长总结章节内容。请为以下剧本/小说生成章节概要。

**要求**：
1. 识别所有章节（如果没有明确分章，按场景或段落自动分章）
2. 为每个章节生成 100-200 字的概要
3. 提取章节关键事件
4. 分析章节情感走向

**输出格式**（JSON）：
```json
{
  "chapters": [
    {
      "chapter_id": "章节 ID 或序号",
      "title": "章节标题（如果有）",
      "summary": "章节内容概要（100-200 字）",
      "key_events": ["关键事件 1", "关键事件 2"],
      "emotion_trend": "情感走向描述"
    }
  ],
  "overall_summary": "整部作品的总体概要"
}
```

**输入内容**：
```
{{content}}
```

请分析并输出 JSON 格式的结果。
