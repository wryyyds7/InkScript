# 剧本结构分析 Skill

分析剧本的结构合理性，包括幕次均衡、节奏分析、角色戏份分布等。

## 功能说明

1. **幕次均衡分析**：检查各幕的场次/台词量是否均衡，给出优化建议
2. **节奏分析**：计算各场景的情绪强度方差，标记"情绪平淡区"和"情绪过山车区"
3. **角色戏份分析**：计算每个角色的台词量占比，标记戏份过少/过多的角色

## 输出格式

JSON 格式的分析报告，包含：
- 幕次均衡分析结果
- 节奏分析结果（情绪平淡区、情绪过山车区）
- 角色戏份分析结果
- 可视化数据（用于雷达图/柱状图/折线图）

## 使用方法

在 Skills 管理页面点击"运行"按钮，或在编辑器中选择"剧本结构分析"。
