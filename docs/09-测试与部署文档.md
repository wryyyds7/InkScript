## 1. 测试概述

### 1.1 测试策略

InkScript 采用**分层测试策略**，确保代码质量和功能正确性：

| 测试层级 | 工具 | 覆盖范围 | 执行频率 |
|---------|------|----------|----------|
| 单元测试 | `pytest` | 单个函数/类 | 每次提交 |
| 集成测试 | `pytest` + `httpx` | API 端点集成 | 每次提交 |
| 端到端测试 | `playwright` (规划中) | 完整用户流程 | 发布前 |
| 性能测试 | `pytest-benchmark` (规划中) | 长文本处理 | 发布前 |
| 安全审计 | `bandit` + `safety` (规划中) | 依赖漏洞、代码安全 | 定期 |

```python
"""配置管理模块单元测试"""
import pytest
from pathlib import Path
from novel2script.config import load_config, save_config, get_decrypted_api_key

class TestConfig:
    """配置管理测试类"""
    
    def test_load_config(self):
        """测试加载配置"""
        config = load_config()
        assert config is not None
        assert hasattr(config, "llm_api_key")
        assert hasattr(config, "llm_model")
    
    def test_save_config(self, tmp_path):
        """测试保存配置"""
        # 使用临时目录
        config_path = tmp_path / "config.yaml"
        save_config({"llm_model": "gpt-4"}, config_path)
        assert config_path.exists()
    
    def test_encrypt_decrypt_api_key(self):
        """测试 API Key 加密解密"""
        from novel2script.config import encrypt_api_key, decrypt_api_key
        
        original_key = "sk-test123456789"
        encrypted = encrypt_api_key(original_key)
        decrypted = decrypt_api_key(encrypted)
        
        assert decrypted == original_key
    
    def test_get_decrypted_api_key(self):
        """测试获取解密后的 API Key"""
        # 先保存加密的 API Key
        save_config({"llm_api_key": encrypt_api_key("sk-test123")})
        
        # 获取解密后的 Key
        decrypted = get_decrypted_api_key()
        assert decrypted == "sk-test123"
```

#### 示例：`tests/integration/test_api.py`

```python
"""API 集成测试"""
import pytest
from fastapi.testclient import TestClient
from novel2script.api.main import app

client = TestClient(app)

class TestProjectsAPI:
    """项目管理 API 测试类"""
    
    def test_create_project(self):
        """测试创建项目"""
        response = client.post(
            "/api/v1/projects",
            json={
                "name": "测试项目",
                "description": "这是一个测试项目",
            }
        )
        assert response.status_code == 200
        data = response.json()
        assert data["code"] == 0
        assert "data" in data
        assert "id" in data["data"]
        return data["data"]["id"]  # 返回项目 ID 供其他测试使用
    
    def test_get_projects(self):
        """测试获取项目列表"""
        response = client.get("/api/v1/projects")
        assert response.status_code == 200
        data = response.json()
        assert data["code"] == 0
        assert "data" in data
        assert isinstance(data["data"], list)
    
    def test_get_project(self):
        """测试获取单个项目"""
        # 先创建项目
        project_id = self.test_create_project()
        
        # 获取项目
        response = client.get(f"/api/v1/projects/{project_id}")
        assert response.status_code == 200
        data = response.json()
        assert data["code"] == 0
        assert data["data"]["id"] == project_id
    
    def test_update_project(self):
        """测试更新项目"""
        # 先创建项目
        project_id = self.test_create_project()
        
        # 更新项目
        response = client.put(
            f"/api/v1/projects/{project_id}",
            json={
                "name": "更新后的项目名称",
                "description": "更新后的描述",
            }
        )
        assert response.status_code == 200
        data = response.json()
        assert data["code"] == 0
        assert data["data"]["name"] == "更新后的项目名称"
    
    def test_delete_project(self):
        """测试删除项目"""
        # 先创建项目
        project_id = self.test_create_project()
        
        # 删除项目
        response = client.delete(f"/api/v1/projects/{project_id}")
        assert response.status_code == 200
        data = response.json()
        assert data["code"] == 0
        
        # 确认项目已删除
        response = client.get(f"/api/v1/projects/{project_id}")
        assert response.status_code == 404
```

## 5. 端到端测试

### 5.1 端到端测试策略

⚠️ **规划中**，尚未实现。

端到端测试将使用 `playwright` 模拟真实用户操作，覆盖完整用户流程：

| 测试场景 | 测试步骤 | 优先级 |
|---------|---------|----------|
| 创建项目 → 上传小说 → 转换 → 查看结果 | 1. 打开应用<br>2. 创建项目<br>3. 上传小说文件<br>4. 点击转换<br>5. 等待完成<br>6. 查看结果 | P0 |
| 编辑剧本 → 保存 → 导出 | 1. 打开项目<br>2. 编辑剧本 YAML<br>3. 保存<br>4. 导出 YAML/TXT | P1 |
| Skill 管理 → 运行 Skill → 查看结果 | 1. 打开 Skill 管理页面<br>2. 选择 Skill<br>3. 运行<br>4. 查看结果 | P1 |
| 版本历史 → 回滚 | 1. 打开项目<br>2. 查看版本历史<br>3. 选择版本<br>4. 回滚 | P2 |
| 回收站 → 恢复项目 | 1. 删除项目<br>2. 打开回收站<br>3. 恢复项目 | P2 |

### 5.2 端到端测试工具选择

| 工具 | 优点 | 缺点 | 推荐度 |
|------|------|------|----------|
| `playwright` | 跨浏览器、支持移动端、API 简单 | 需要学习 | ⭐⭐⭐⭐⭐ |
| `selenium` | 成熟、社区大 | 速度慢、API 复杂 | ⭐⭐⭐ |
| `cypress` | 前端友好、实时重载 | 不支持多标签页 | ⭐⭐⭐ |

**推荐**：使用 `playwright`（Python 版本）

### 5.3 端到端测试示例（规划中）

```python
"""端到端测试（使用 playwright）"""
import pytest
from playwright.sync_api import sync_playwright

def test_create_project_and_convert():
    """测试完整流程：创建项目 → 上传小说 → 转换 → 查看结果"""
    with sync_playwright() as p:
        # 启动浏览器
        browser = p.chromium.launch(headless=False)
        page = browser.new_page()
        
        # 1. 打开应用
        page.goto("http://127.0.0.1:8000")
        
        # 2. 创建项目
        page.click("text=创建项目")
        page.fill("input[name='name']", "测试项目")
        page.fill("textarea[name='description']", "这是一个测试项目")
        page.click("button:text('创建')")
        
        # 3. 上传小说文件
        page.set_input_files("input[type='file']", "tests/fixtures/novel.txt")
        
        # 4. 点击转换
        page.click("button:text('开始转换')")
        
        # 5. 等待完成
        page.wait_for_selector("text=转换完成")
        
        # 6. 查看结果
        assert page.is_visible("text=剧本 YAML")
        
        # 关闭浏览器
        browser.close()
```

## 10. GitHub Release

### 10.1 GitHub Release 流程

1. **更新版本号**（`novel2script/__init__.py`）
2. **更新 CHANGELOG.md**
3. **创建 Git 标签**
4. **推送标签到 GitHub**
5. **GitHub Actions 自动打包**
6. **创建 Release**
7. **上传打包文件**
8. **发布 Release**

### 10.2 GitHub Actions 配置（规划中）

```yaml
# .github/workflows/release.yml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.10'
    
    - name: Install dependencies
      run: |
        pip install -e ".[dev]"
        pip install pyinstaller
    
    - name: Build with PyInstaller
      run: pyinstaller novel2script.spec
    
    - name: Upload artifacts
      uses: actions/upload-artifact@v3
      with:
        name: novel2script-${{ matrix.os }}
        path: dist/
  
  release:
    needs: build
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    
    - name: Download artifacts
      uses: actions/download-artifact@v3
    
    - name: Create Release
      uses: softprops/action-gh-release@v1
      with:
        files: |
          novel2script-ubuntu-latest/*
          novel2script-windows-latest/*
          novel2script-macos-latest/*
        body_path: CHANGELOG.md
      env:
        GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## 12. 故障排查

### 12.1 常见问题

#### 问题1：PyInstaller 打包失败

**现象**：`ModuleNotFoundError: No module named 'xxx'`

**原因**：PyInstaller 未自动包含某些隐式导入的模块。

**解决**：在 `novel2script.spec` 的 `hiddenimports` 中添加缺失的模块。

```python
hiddenimports=[
    'novel2script.api.main',
    'novel2script.core.pipeline',
    'webview',  # 手动添加
    'cryptography',  # 手动添加
]
```

#### 问题2：打包后运行报错 `FileNotFoundError`

**现象**：`FileNotFoundError: [Errno 2] No such file or directory: 'novel2script/web/index.html'`

**原因**：PyInstaller 未将静态文件打包进可执行文件。

**解决**：在 `novel2script.spec` 的 `datas` 中添加静态文件。

```python
datas=[
    ('novel2script/web', 'novel2script/web'),
    ('novel2script/skills', 'novel2script/skills'),
]
```

#### 问题3：API Key 加密失败

**现象**：`cryptography.fernet.InvalidToken`

**原因**：加密密钥文件 `~/.novel2script/.key` 丢失或损坏。

**解决**：删除旧的密钥文件，重新生成。

```bash
rm ~/.novel2script/.key
novel2script config --set llm_api_key "sk-test123"
```
