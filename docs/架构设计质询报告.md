**回答**：✅ **应该自动重试**（最多 3 次，指数退避）。

**回答**：❌ **不准确**。应该使用**保守估计**（1 个字符 = 1 个 token）。

**完善措施**：
- 修改 `calculate_threshold()` 函数，使用保守估计：
  ```python

      """保守估计：1 个字符 = 1 个 token"""

      return threshold
  ```

### 问题 5.3：API Key 是否应该加密存储？

**回答**：✅ **应该加密存储**。

**完善措施**：
- 使用 `cryptography` 库的 **Fernet 对称加密**，密钥存储在操作系统提供的密钥管理服务中（Windows DPAPI、macOS Keychain、Linux Secret Service）
- 加密流程：
  1. 用户首次输入 API Key 时，程序生成 Fernet 密钥（存在内存中）
  2. 将 Fernet 密钥保存到操作系统密钥管理服务
  3. 使用 Fernet 密钥加密 API Key，并保存到 `config.json`
  4. 下次启动时，从操作系统密钥管理服务读取 Fernet 密钥，解密 `config.json` 中的 API Key
- 依赖：`cryptography`、`keyring`

**修改位置**：`docs/architecture.md` 第 8.2.1 节
