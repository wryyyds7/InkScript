## 2. 设置界面重构

### 2.1 布局变更
- **旧版**：单页布局，所有设置项堆叠显示
- **新版**：左侧侧边栏 + 右侧内容区的双栏布局

### 2.2 侧边栏选项
| 选项 | 图标 | 说明 |
|------|------|------|
| AI 设置 | 灯泡图标 | 配置 AI 提供商、API Key、模型（默认激活） |
| 模型参数 | 齿轮图标 | 调整温度、Top P、Max Tokens 等参数 |
| API 设置 | 分享图标 | 配置超时、重试次数、请求间隔 |
| 关于 | 信息图标 | 显示版本信息和帮助链接 |

### 2.3 AI 设置面板
- **AI 提供商选择**：支持 OpenAI、DeepSeek、Anthropic、通义千问、Gemini、自定义
- **动态提示**：选择提供商后，自动显示典型的 API Base URL
- **模型名称占位符**：根据选择的提供商，显示对应的模型名称提示

### 2.4 模型参数面板
- **温度 (Temperature)**：控制生成创意度 (0-2)
- **Top P**：控制生成多样性 (0-1)
- **Max Tokens**：单次请求最大 Token 数
- **Frequency Penalty**：降低重复词汇频率 (0-2)
- **Presence Penalty**：鼓励引入新话题 (0-2)

### 2.5 API 设置面板
- **请求超时**：API 调用超时时间（秒）
- **重试次数**：失败重试次数
- **API 调用间隔**：避免触发速率限制
- **提示栏**：展示典型 AI 的 API Base URL 参考

## 6. Bug 修复

### 6.1 修复点击设置后返回导致项目列表消失
- **问题**：使用 `innerHTML` 插入的项目列表在视图切换后消失
- **原因**：`renderProjectList()` 使用 `innerHTML` 插入带 Alpine 事件的 HTML，这些事件不会被 Alpine 识别
- **解决**：移除 `renderProjectList()` 方法，改用 Alpine 的 `x-for` 指令直接绑定项目列表

### 6.2 修复编辑器无法打开
- **问题**：点击项目后编辑器视图无法正常加载
- **原因**：`openProject()` 方法没有加载剧本数据
- **解决**：在 `openProject()` 中添加 `await this.loadScript()` 调用

## 10. Bug修复

### 10.1 修复FastAPI报错
- **问题**：`RuntimeError: no running event loop` 发生在 `convert.py` 第50行
- **原因**：`_before_hook` 是同步函数，内部调用 `asyncio.create_task()` 导致错误
- **解决**：使用 `asyncio.run_coroutine_threadsafe()` 替代 `asyncio.create_task()`

### 10.2 前端内容校验
- **功能**：若小说内容为空或字数少于300字，界面展示错误提示，阻止后续操作
- **实现**：在 `app.js` 的 `startConvert()` 中添加校验逻辑，在 `index.html` 中添加错误提示UI

## 11. 竞品调研新增功能建议（2026-06-06）

> 依据：`docs/竞品调研报告.md` + 2026 年竞品最新动态（Final Draft 13、WriterDuet、Celtx、Laper、dr.aft 等）

### 11.1 变更概述

本次基于竞品最新动态，在现有 `待实现功能清单.md` 基础上，新增 **15 项功能建议**，并同步更新了 `PRD.md` 和新建 `待实现功能清单（新增）.md`。

**核心发现**：
1. **可视化是核心差异化方向**：竞品普遍具备情绪曲线、角色图谱、节拍板等可视化功能
2. **版本历史需要细化**：现有规划只有"快照级"版本，需增强为"逐句修改历史"
3. **制作素材派生是高价值扩展**：从剧本延伸到制片流程，可大幅提升工具的专业度
4. **协作功能是长期方向**：纯本地工具适合个人用户，但团队协作是专业场景的刚需
