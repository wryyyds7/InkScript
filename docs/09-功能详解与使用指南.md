# InkScript 功能详解与使用指南

> 更新时间：2026-06-08  
> 版本：V1.0

---

## 一、项目概述

InkScript 是一款将**小说自动转换为结构化剧本**的桌面应用。用户粘贴小说文本后，AI 自动识别角色、分割场景、解析对白与动作，生成 YAML 格式的结构化剧本，并支持导出为 TXT/HTML/Fountain 等多种格式。

### 核心优势

| 特性 | 说明 |
|------|------|
| 🤖 **AI 驱动** | 使用 DeepSeek V3 大模型，自动识别角色、场景、对白、情绪 |
| 📝 **结构化输出** | 生成 YAML 剧本，包含 dialogue（对白）、action（动作）、narration（旁白）三种 beat |
| 🎬 **镜头指示** | AI 自动添加（中景/近景/特写/闪回等）镜头描述 |
| 📊 **可视化分析** | 情绪曲线图、角色雷达图、角色情绪分布统计 |
| 🔧 **Skills 系统** | 11 个内置 Skill，支持手动运行或集成到转换 Pipeline |
| 📤 **多格式导出** | 支持 YAML/TXT/HTML/Fountain 四种格式导出 |
| 💾 **本地存储** | 项目数据保存在本地文件系统，完全离线可用 |

## 二、转换引擎

### 2.1 转换流程

```
用户点击"开始转换"
  ↓
1. text_splitter     — 文本分段（将长文本按 2 万字符切分）
  ↓
2. character_extractor — AI 识别角色（提取姓名、别名、外貌性格描述）
  ↓
3. scene_splitter    — AI 分割场景（按地点/时间变化划分）
  ↓
4. dialogue_parser   — AI 解析对白与动作（最核心的步骤）
  ↓
5. emotion_tagger    — AI 标注情绪（happy/sad/angry/calm/excited 等 13 种）
  ↓
6. yaml_generator    — 生成 YAML 剧本文件
  ↓
7. format_converter  — 本地导出 TXT/HTML/Fountain（不调 API）
```

### 2.2 dialogue_parser 详解

这是最关键的步骤。AI 将小说文本转换为三种 beat：

| Beat 类型 | 说明 | 示例 |
|-----------|------|------|
| `dialogue` | 角色对白 | `character: "荻原明"`, `content: "怎么，决定好了吗"`, `emotion: "calm"` |
| `action` | 动作/场景描述 | `content: "（中景）荻原明靠在吊椅上，悠闲地翘着腿"` |
| `narration` | 旁白/内心独白 | `content: "霞之丘诗羽意识到荻原明有能力帮她摆脱困境"` |

**镜头指示**：AI 自动添加（远景/中景/近景/特写/大特写/闪回/叠化转场/冷色调/暖色调）等。

**情绪标注**：支持 13 种情绪：happy/sad/angry/calm/excited/fear/surprised/confident/firm/cold/curious/mock/embarrassed。

### 2.3 性能优化

- **长文本分段**：每段 4000 字符调用一次 AI，避免单次 prompt 过长
- **DeepSeek V3**：128K 上下文窗口，max_tokens=8192
- **容错机制**：单个 Step 失败后自动跳过继续执行

## 四、角色分析面板

### 4.1 角色列表

点击"角色"按钮，从当前剧本 YAML 中自动解析角色列表，显示：
- 角色名和别名
- 对白数量统计
- 情绪分布（百分比）

### 4.2 情绪雷达图

点击某个角色后，展示六维雷达图：
- 😊 快乐 / 😢 悲伤 / 😡 愤怒 / 😐 平静 / 🎉 兴奋 / 😨 恐惧
- 基于该角色所有对白的 emotion 字段统计

## 五、情绪曲线

### 5.1 功能说明

点击"情绪曲线"按钮，以折线图展示剧本中所有 Beat 的情绪变化趋势。

### 5.2 粒度切换

| 粒度 | 说明 |
|------|------|
| Beat 级 | 每个 Beat 一个数据点（默认） |
| 场景级 | 每个场景取平均情绪强度 |

### 5.3 交互

点击图表上的数据点 → 自动定位到剧本编辑器中对应的 Beat 位置。

## 六、Skills 系统

### 6.1 什么是 Skills

Skills 是对剧本进行**后处理**的功能模块。每个 Skill 是一个独立的 Python 脚本（`main.py`），包含 `run(data, config)` 函数。

### 6.2 内置 Skills

| Skill 名称 | 功能 | 类型 |
|-----------|------|------|
| `character-analysis` | 统计角色对白数、对白长度、情绪分布 | 分析 |
| `character-profile` | 生成角色人物小传 Markdown | 生成 |
| `chapter-summary` | 生成章节摘要 | 分析 |
| `dialogue-polish` | 润色对白内容 | 编辑 |
| `fountain-export` | 导出 Fountain 剧本格式 | 导出 |
| `html-export` | 导出自包含 HTML 剧本页面 | 导出 |
| `props-list-gen` | 生成道具列表 | 分析 |
| `storyboard-gen` | 生成分镜建议 | 生成 |
| `structure-analytics` | 分析剧本结构（幕次、节奏） | 分析 |
| `style-adapt` | 风格适配 | 编辑 |
| `casting-suggester` | 选角建议（含匹配度评分） | 推荐 |

### 6.3 使用方式

**手动运行**：
1. 点击顶部 "Skills" 按钮进入 Skills 页面
2. 点击 Skill 旁边的"运行"按钮
3. 结果弹窗显示

**集成到 Pipeline**：
1. 在 Skills 页面点击"启用"需要的 Skills
2. 回到编辑器，勾选 🧩 Skills 复选框
3. 点击"开始转换"，转换完成后自动运行所有已启用的 Skills

### 6.4 运行机制

```
前端点击"运行" 
  → POST /api/v1/skills/{name}/run {project_id, yaml_content}
  → 后端动态加载 skills/builtins/{name}/main.py
  → 调用 run(data, config)
  → 返回 JSON 结果
```

> **注意**：当前 Skills 均为纯本地运算（正则匹配、数据统计），不调用 AI API，所以运行速度很快（秒回）。

## 七、格式导出

### 7.1 支持的格式

| 格式 | 说明 | 用途 |
|------|------|------|
| YAML | 结构化剧本 | 编辑器编辑、版本控制 |
| TXT | 纯文本剧本 | 打印、阅读 |
| HTML | 网页剧本 | 浏览器查看，带 CSS 样式 |
| Fountain | 专业剧本格式 | 导入 Final Draft 等软件 |

### 7.2 自动导出

转换完成后，TXT/HTML/Fountain 三种格式**自动生成**并保存到项目目录：
```
projects/{project_id}/
├── script.yaml      # YAML 剧本
├── script.txt       # TXT 剧本
├── script.html      # HTML 剧本
└── script.fountain  # Fountain 剧本
```

## 八、设置

### 8.1 AI 配置

在设置页面可配置：
- **AI 提供商**：OpenAI / DeepSeek / Anthropic / 通义千问 / Gemini / 自定义
- **Base URL**：API 端点地址
- **API Key**：明文存储到本地 `config.json`
- **模型名称**：如 `deepseek-v4-pro`、`gpt-4o`
- **温度/Top-P/Max Tokens**：控制生成随机性和长度

### 8.2 数据存储

所有项目数据保存在：
```
C:\Users\{用户名}\.novel2script\
├── config.json       # AI 配置
├── projects/         # 项目数据
│   └── {project_id}/
│       ├── meta.json
│       ├── novel.txt
│       ├── script.yaml
│       ├── script.txt
│       ├── script.html
│       └── script.fountain
└── skills/           # Skills 配置
```

## 十、启动方式

```powershell
# 开发模式（浏览器访问 http://127.0.0.1:8000）
novel2script gui

# 仅启动后端服务
novel2script serve

# 命令行转换
novel2script convert input.txt -o output.yaml
```
