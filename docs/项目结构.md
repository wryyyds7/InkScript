## 1. 项目概览

**InkScript**（代码代号 `novel2script`）是一款本地安装的桌面级应用，将小说文本自动转换为结构化剧本 YAML。

| 项目信息 | 说明 |
|---------|------|
| 仓库地址 | `https://github.com/wryyyds7/InkScript` |
| 开发状态 | 设计阶段，代码骨架搭建中 |
| 技术栈 | Python + FastAPI + PyWebView + Alpine.js + CodeMirror 6 |
| 入口命令 | `novel2script gui` / `convert` / `serve` |

## 3. 各模块详细说明

### 3.1 启动层

| 文件 | 作用 |
|------|------|
| `src/__main__.py` | 统一入口，根据命令行参数分发到 `gui` / `serve` / `convert` |
| `src/cli.py` | Typer CLI 定义：`gui` / `serve` / `convert` / `config` / `skill` 子命令 |
| `src/desktop/window.py` | PyWebView 桌面窗口：后台线程运行 FastAPI，前台创建窗口 |

**设计要点**：
- 双击 exe → 无参数 → 默认 `gui`
- `pywebview` 未安装时自动回退到浏览器模式

---

### 3.2 API 层

| 文件 | 作用 |
|------|------|
| `src/api/main.py` | FastAPI app 创建、`lifespan` 生命周期（初始化配置/ProjectStore/SkillManager）、中间件注册、静态文件挂载 |
| `src/api/routes/v1/convert.py` | 转换相关 API：`/start` `/status` `/result` `/cancel` |
| `src/api/routes/v1/config.py` | 配置 API：`GET/PUT /test` |
| `src/api/routes/v1/files.py` | 文件上传下载 API |
| `src/api/routes/v1/projects.py` | 项目管理 API：`list` `create` `get` `delete` |
| `src/api/routes/v1/editor.py` | 编辑器 API：`save_novel` `save_script` `update_beat` |
| `src/api/routes/v1/skills.py` | Skill API：`list` `run` `toggle` `create` `install` `uninstall` |
| `src/api/sse.py` | SSE 事件推送管理 |

**设计要点**：
- 所有 V1 接口在 `/api/v1/` 下
- V2 新接口放 `/api/v2/`，老版本保留至少一个大版本周期

---

### 3.3 核心 Pipeline

| 文件 | 作用 |
|------|------|
| `src/core/pipeline.py` | 流水线编排：步骤注册/`reorder_steps()`/`skip_steps()`/Hook 机制/`run()`/`run_chapters()` |
| `src/core/steps/base.py` | `StepProtocol` 定义：`name` / `run()` / `validate()` / `depends_on` |
| `src/core/steps/character_extractor.py` | 步骤：角色识别（全量，LLM + 规则去重） |
| `src/core/steps/scene_splitter.py` | 步骤：场景分割（按时空变化，LLM） |
| `src/core/steps/dialogue_parser.py` | 步骤：对白/动作/旁白解析（LLM） |
| `src/core/steps/emotion_tagger.py` | 步骤：情绪标注（LLM，含复审逻辑） |
| `src/core/steps/yaml_generator.py` | 步骤：YAML 生成 + Pydantic 校验 |
| `src/core/text_segmenter.py` | 长文本智能分段（>6000字触发，保留200字上下文窗口） |
| `src/core/merger.py` | 分段结果合并（角色ID全局统一） |
| `src/core/project_store.py` | `ProjectStore` Protocol + `FileSystemProjectStore` 默认实现 |

**Pipeline 执行流程**：
```
输入文件 → Hook:before_convert → pre_processor Skills
  → text_segmenter.segment()
  → Step: character_extractor → Hook:after_step
  → Step: scene_splitter      → Hook:after_step
  → Step: dialogue_parser     → Hook:after_step（场景级并行）
  → Step: emotion_tagger     → Hook:after_step
  → merger.merge()
  → Step: yaml_generator     → Hook:after_step
  → Step: quality_checker   → Hook:after_step
  → Hook:after_convert
  → post_processor Skills → exporter Skills
  → 输出结果
```

---

### 3.4 LLM 客户端

| 文件 | 作用 |
|------|------|
| `src/llm_client.py` | `LLMClientProtocol` 定义 + `OpenAIClient` 实现（含重试/超时/JSON解析修复） |

**设计要点**：
- 通过 `LLMClientProtocol` 封装，后续加 Ollama/其他模型只需写新实现类

---

### 3.5 Schema（Pydantic V2）

| 文件 | 作用 |
|------|------|
| `src/schema.py` | 所有 Pydantic 数据模型定义：`Script` / `Character` / `Act` / `Scene` / `Beat`（Tagged Union）/ `Prop` / `Foreshadowing` |

**核心模型**：
- ` Beat = DialogueBeat | ActionBeat | NarrationBeat | TransitionBeat`（Tagged Union）
- 每个 Beat 可选含 `source_location: SourceLocation`（用于滚动联动和原文溯源）

---

### 3.6 配置管理

| 文件 | 作用 |
|------|------|
| `src/config.py` | `AppConfig`（pydantic-settings）：LLM配置/Pipeline配置/功能开关/项目管理配置/Skill配置 |

**配置层级**（优先级从低到高）：
```
默认值（代码中）
  ↓ 覆盖
全局配置文件（~/.novel2script/config.json）
  ↓ 覆盖
项目配置快照（config_snapshot.json）
  ↓ 覆盖
环境变量（N2S_ 前缀）
  ↓ 覆盖
运行时参数（CLI --option / API 请求体）
```

---

### 3.7 Skill 系统

| 文件 | 作用 |
|------|------|
| `src/skills/manager.py` | `SkillManager`：发现/加载/执行/启用禁用/生命周期钩子 |
| `src/skills/fountain_export/main.py` | 内置 Skill：YAML → Fountain 导出 |
| `src/skills/character_report/main.py` | 内置 Skill：角色分析 + 关系图谱 |
| `src/skills/dialogue_polish/main.py` | 内置 Skill：对白润色（需 LLM） |
| `src/skills/style_adapter/main.py` | 内置 Skill：风格适配（电影/电视剧/话剧） |
| `src/skills/chapter_summary/main.py` | 内置 Skill：章节概要生成 |

**Skill 类型**：
| 类型 | 执行时机 | 示例 |
|------|---------|------|
| `pre_processor` | Pipeline 转换前 | 文本清洗 |
| `post_processor` | Pipeline 转换后 | 对白润色、风格适配 |
| `exporter` | 用户主动触发 | Fountain 导出 |
| `analyzer` | 用户主动触发 | 角色分析、章节概要 |

### 3.8 前端（Web UI）

| 文件 | 作用 |
|------|------|
| `src/web/index.html` | 主页面（Alpine.js + Tailwind CSS CDN） |
| `src/web/js/app.js` | 主应用：路由注册 + 事件总线 + 组件注册表 |
| `src/web/js/editor.js` | CodeMirror 6 编辑器初始化（小说面板 + YAML面板） |
| `src/web/js/event-bus.js` | 全局事件总线：`beat:updated` / `novel:changed` 等 |
| `src/web/js/scroll-sync.js` | 滚动联动：点击 Beat → 左侧定位原文 |
| `src/web/js/beat-editors.js` | Beat 内联编辑器注册表（按 Beat 类型分发） |
| `src/web/js/skills.js` | Skill 管理面板逻辑 |
| `src/web/js/api.js` | 前端 API 调用封装 |
| `src/web/js/sse.js` | SSE 实时进度推送客户端 |

**编辑器架构要点**：
- 左面板：小说原文（CodeMirror 6 + 章节折叠 Extension）
- 右面板：YAML 剧本（CodeMirror 6 + Schema 校验 lint Extension）
- 滚动联动：通过 `source_location` 字段映射

## 5. 关键技术决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 后端框架 | **FastAPI** | 异步原生/SSE 支持/自动生成 OpenAPI 文档 |
| 桌面窗口 | **pywebview** | 轻量（~5MB）/Python 原生/跨平台 |
| 前端框架 | **Alpine.js + CodeMirror 6** | 零构建/CDN引入/模块化 Extension 架构 |
| LLM 客户端 | **openai SDK** | 兼容所有 OpenAI API 格式的服务商 |
| YAML 处理 | **PyYAML + Pydantic V2** | 类型安全/Schema 校验/JSON Schema 导出 |
| CLI 框架 | **Typer + Rich** | 简洁/自动帮助文档/美观输出 |
| 实时通信 | **SSE** | 单向推送够用/比 WebSocket 简单/FastAPI 原生支持 |
| Skill 加载 | **importlib 动态加载** | 标准库/运行时发现/无需重启 |
| 打包方案 | **PyInstaller** | 成熟稳定/单文件或单目录/自动收集依赖 |
