## 1. 文档目的与范围

### 1.1 目的

本文档将 PRD 中的功能需求转化为**可测试、可验收的规格说明**，作为：
- 架构设计的输入
- 详细设计的依据
- 测试用例编写的基准
- 用户验收测试（UAT）的标准

### 1.2 范围

| 包含 | 不包含 |
|------|---------|
| V1 版本所有功能需求 | V2/V3 迭代功能 |
| 功能性需求 + 非功能性需求 | 市场分析、商业模式 |
| 用户交互规格 | 内部实现细节（归架构/详细设计） |

### 1.3 需求优先级定义

| 优先级 | 含义 | 验收条件 |
|---------|------|---------|
| **P0** | 必须有，否则产品不可用 | 必须 100% 通过测试 |
| **P1** | 应该有，影响核心体验 | 必须 ≥ 80% 通过测试 |
| **P2** | 可以有，锦上添花 | 资源允许时实现 |

### F-001：桌面窗口模式（PyWebView）

**模块**：M1.1 | **优先级**：P0 | **来源**：PRD 2.1

#### 描述

应用默认以桌面窗口模式启动（双击 exe 或运行 `novel2script gui`），使用 PyWebView 创建独立窗口，加载本地 Web 服务。

#### 详细规格

| 规格项 | 说明 |
|---------|------|
| 窗口标题 | "Novel2Script" |
| 窗口图标 | 显示任务栏图标 |
| 窗口尺寸 | 默认 1280×800，可调整，最小 960×600 |
| 地址栏 | 无地址栏（PyWebView 独立窗口） |
| 关闭行为 | 关闭窗口即退出整个程序 |
| 回退机制 | PyWebView 未安装时自动回退到浏览器模式 |

#### 验收标准

| ID | 验收条件 | 测试方法 |
|-----|---------|---------|
| AC-001-01 | 双击 exe 启动后，窗口标题显示 "Novel2Script" | 手动/自动化 UI 测试 |
| AC-001-02 | 窗口默认尺寸 1280×800，可拖拽缩放至最小 960×600 | 手动测试 |
| AC-001-03 | 关闭窗口后，进程完全退出（无后台进程） | 任务管理器检查 |
| AC-001-04 | PyWebView 未安装时，自动打开默认浏览器访问 `http://localhost:8765` | 卸载 pywebview 后测试 |

### F-002：CLI 模式

**模块**：M1.2 | **优先级**：P0 | **来源**：PRD 2.2

#### 描述

提供命令行接口，支持无 GUI 环境下的转换、校验、Skill 执行。

#### 详细规格

| 子命令 | 参数 | 功能 |
|---------|------|------|
| `novel2script convert <input> <output_dir>` | `--model`, `--api-key`, `--no-emotion`, `--format` | 执行完整转换 |
| `novel2script validate <yaml_path>` | 无 | 校验 YAML 文件 |
| `novel2script skill run <name> --input <yaml_text>` | 无 | 运行指定 Skill |
| `novel2script config` | `--set-key`, `--set-model` | 查看/修改配置 |
| `novel2script serve` | `--host`, `--port` | 启动 Web 服务器 |

#### 验收标准

| ID | 验收条件 | 测试方法 |
|-----|---------|---------|
| AC-002-01 | `convert` 命令输入 .txt/.md，输出 .yaml 到指定目录 | 命令行测试 |
| AC-002-02 | `validate` 命令对合法 YAML 返回退出码 0，非法返回 1 | 自动化测试 |
| AC-002-03 | `skill run` 执行 Skill 并在终端输出结果 | 命令行测试 |
| AC-002-04 | `--model`/`--api-key` 参数正确传递到 Pipeline | 单元测试 |
| AC-002-05 | `--format yaml\|json\|fountain` 正确输出对应格式 | 自动化测试 |
| AC-002-06 | 进度输出到 stderr，`--no-progress` 关闭进度 | 命令行测试 |

### F-013：内置 Skill

**模块**：M4.1 | **优先级**：P0 | **来源**：PRD 5.1

#### 详细规格

5 个内置 Skill：

| # | 名称 | 类型 | 需要 LLM | 功能 |
|---|------|------|---------|------|
| 1 | `fountain_export` | exporter | ❌ | YAML → Fountain 格式导出 |
| 2 | `character_report` | analyzer | ❌ | 角色分析 + 关系图谱 |
| 3 | `dialogue_polish` | post_processor | ✅ | 对白润色（修正翻译腔、增强语言个性） |
| 4 | `style_adapter` | post_processor | ✅ | 风格适配（电影/电视/话剧/动画） |
| 5 | `chapter_summary` | analyzer | ❌ | 章节概要生成 |

#### 验收标准

| ID | 验收条件 |
|-----|---------|
| AC-013-01 | 5 个内置 Skill 随程序打包，无需额外安装 |
| AC-013-02 | `fountain_export` 正确将 YAML 转为 Fountain 格式 |
| AC-013-03 | `dialogue_polish` 调用 LLM 对对白进行润色 |
| AC-013-04 | Skill 执行错误时，不影响核心 Pipeline，但记录错误日志并推送前端 |
| AC-013-05 | 所有内置 Skill 可通过 `novel2script skill run <name>` 执行 |

### F-017：API Key 管理

**模块**：M5.2 | **优先级**：P0 | **来源**：PRD 6.2

#### 详细规格

| 功能点 | 说明 |
|---------|------|
| 存储方式 | API Key 使用 Fernet 对称加密后存储到配置文件 |
| 加密密钥 | 存储在操作系统密钥管理服务（Windows DPAPI / macOS Keychain / Linux Secret Service） |
| GET 接口 | 返回 API Key 末 4 位（如 `sk-****a1b2`），避免泄露 |
| PUT 接口 | 支持完整 Key 写入 |

## 5. 数据需求

### 5.1 数据模型（概要）

详细模型定义见 `docs/yaml-schema.md` 和架构设计文档。

**核心模型**：

```
Script
├── meta: MetaData
├── characters: list[Character]
└── scenes: list[Scene]
    └── beats: list[Beat]   ← Tagged Union
        ├── DialogueBeat { character, content, emotion }
        ├── ActionBeat { content }
        └── NarrationBeat { content }
```

### 5.2 数据存储

| 数据类型 | 存储方式 | 路径 |
|---------|---------|------|
| 项目元信息 | JSON | `~/.novel2script/projects/<project_id>/meta.json` |
| 小说原文 | 纯文本 | `~/.novel2script/projects/<project_id>/novel.txt` |
| YAML 剧本 | YAML | `~/.novel2script/projects/<project_id>/script.yaml` |
| 版本快照 | YAML | `~/.novel2script/projects/<project_id>/versions/script_vN.yaml` |
| 配置 | JSON（API Key 加密） | `~/.novel2script/config.json` |
| 配置快照 | JSON | `~/.novel2script/projects/<project_id>/config_snapshot.json` |
| 回收站 | 目录移动 | `~/.novel2script/trash/<project_id>_<timestamp>/` |

## 7. 约束与假设

### 7.1 约束

| 约束 ID | 描述 | 影响 |
|---------|------|-------|
| C-001 | 本地安装运行，不依赖云服务（除 LLM API 外） | 所有数据存储在本地 |
| C-002 | 运行环境为普通笔记本（8-16GB 内存，无 GPU 要求） | 内存占用需控制在 150MB 以内 |
| C-003 | 前端不允许引入 Node.js 构建流程 | 使用 CDN 引入 Alpine.js / CodeMirror 6 |

| C-005 | 打包为 exe 后用户无需安装 Python | 使用 PyInstaller 打包 |

### 7.2 假设

| 假设 ID | 描述 | 风险 |
|---------|------|------|
| A-001 | 用户有自己的 AI API Key（OpenAI / DeepSeek 等） | 如果用户没有 API Key，无法使用 AI 功能 |
| A-002 | 用户输入的小说文本是中文或英文 | 其他语言可能转换质量下降 |
| A-003 | LLM 提供商支持 OpenAI API 兼容格式 | 如果不兼容，需要额外适配 |
| A-004 | 操作系统支持系统 WebView（Windows 10+ / macOS 12+ / Linux with WebKitGTK） | 如果系统 WebView 不可用，回退到浏览器模式 |
